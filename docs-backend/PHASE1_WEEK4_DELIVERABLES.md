### 2. Payment Webhook Handler ✅

**Files Created:**
- ✅ **PaymentWebhookController.java** - Webhook endpoint handler

**Key Features:**
- Receives webhook callbacks from Razorpay
- Verifies webhook signature with HmacSHA256
- Handles 3 webhook events:
  - `payment_link.paid` - Payment successful
  - `payment_link.expired` - Payment timeout
  - `payment_link.cancelled` - Customer cancelled
- Updates Order and WaitlistReservation status atomically
- Idempotent webhook handling (safe to replay)

**Endpoint:**
- `POST /api/v1/payments/webhook/razorpay`

**Event Handling:**
1. **payment_link.paid**
   - Order.paymentStatus = SUCCESS
   - Order.paidAt = NOW()
   - WaitlistReservation.status = PAID_READY_FOR_PICKUP

2. **payment_link.expired**
   - Order.paymentStatus = FAILED
   - WaitlistReservation.status = CANCELLED
   - Release allocation back to available_yield_kg

3. **payment_link.cancelled**
   - Same as expired (customer cancelled)

## 🔄 PAYMENT FLOW

```
Customer Makes Payment:
  ↓
Customer clicks UPI link (generated by RazorpayPaymentServiceImpl)
  ↓
Razorpay payment gateway processes payment
  ↓
Razorpay sends webhook callback: POST /api/v1/payments/webhook/razorpay
  ↓
PaymentWebhookController receives webhook
  ↓
Verify signature with HmacSHA256 (PaymentService.verifyWebhookSignature)
  ↓
If valid and payment_link.paid:
  ├─ Update Order: paymentStatus = SUCCESS, paidAt = NOW()
  └─ Update Reservation: status = PAID_READY_FOR_PICKUP
  ↓
Order appears in logistics manifest (AdminLogisticsController)
  ↓
Admin generates manifest and packs goods
  ↓
Customer picks up at scheduled location
  ↓
Admin marks pickup: OrderService.markOrderAsPickedUp()
  ↓
Order marked COMPLETED, customer notified
```

## 🔒 SECURITY IMPLEMENTATION

### Razorpay Webhook Signature Verification

**Algorithm:** HmacSHA256 (no external SDK)

```java
Key: Razorpay Webhook Secret
Hash: HMAC-SHA256(webhook_body)
Compare: hash == X-Razorpay-Signature header (constant-time)
```

**Protection:**
- ✅ Verifies webhook comes from Razorpay (authenticity)
- ✅ Prevents replay attacks (signature is unique per payload)
- ✅ Constant-time comparison prevents timing attacks
- ✅ Idempotent handling (safe to process same webhook twice)

### API Credential Security

- ✅ Read from environment variables (not committed)
- ✅ Use Spring @ConfigurationProperties
- ✅ Support multiple environments (test/live)
- ✅ Timeout on API calls (30s default)

### Issue: Webhook signature verification fails
**Solution:** 
- Verify RAZORPAY_WEBHOOK_SECRET is correct
- Check webhook secret in Razorpay dashboard
- Ensure raw request body is used (not parsed JSON)

### Issue: Payment link generation fails (401 Unauthorized)
**Solution:**
- Verify RAZORPAY_KEY_ID and RAZORPAY_KEY_SECRET
